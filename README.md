# Laser Knowledge System

A local-first desktop application for recording and browsing optimized laser settings by material.

Each saved profile contains a material name and exactly five print settings:

- Conversion
- Direction
- Speed (mm/min)
- Power (S-Value / %)
- Quality (LPI / interval)

The Library shows material names first. Open a material to view and edit its saved setting cards. Experiment rows and unfinished-record drafts use the same five-setting format; a record is added to the Library only when saved.
